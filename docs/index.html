file2video config generator

Build a file2video.conf file for the file2video CLI. Drop it in the directory where you run the program (or pass --config <PATH>) and every value below becomes a default for encode, decode, estimate and benchmark. Command-line flags always override this file. Encrypting with a password is always on; everything here is optional tuning.

Hardware

Encryption. Video files are always encrypted with a password (AES-GCM + PBKDF2). There is deliberately no way to disable this: the video files travel through YouTube and other platforms and must stay private. Tuning the work factor with pbkdf2_iterations is the supported way to make encoding cheaper or stronger.

file2video.conf

Save this as file2video.conf next to file2video.exe / in your working directory, or pass it explicitly with --config file2video.conf. The encoder also keeps its benchmark results in file2video-calibration.conf; with optimise set, it reuses them automatically and re-calibrates whenever your hardware changes.
